# `vx=0.2` 六组对照结果

固定评估的单位距离能耗统一按总和比值计算：

```text
E_pos / d_x = sum(positive_energy) / sum(distance_x)
E_neg / d_x = sum(negative_energy) / sum(distance_x)
E_abs / d_x = (sum(positive_energy) + sum(negative_energy)) / sum(distance_x)
```

`reducer_corrected_8` 使用额定转矩 $T_N=2.1\,\mathrm{N\,m}$，其训练 cost（代价）为：

$$
P_{\mathrm{cost}}
=
\sum_j\left(\frac{P_j^+}{\eta(x_j)}+P_j^-\right),
\qquad
x_j=\frac{|T_j|}{T_N},
\qquad
\eta(x_j)=\frac{0.905x_j}{x_j+0.2735}.
$$

rc8 结果来自原始 `model_3000.pt` 续训 1000 iterations（迭代）后的 `model_4001.pt`，使用 `8192 env`、`seed=0`、`train_command_x=0.2` 和 `cost_limit1=128.3362`。

## rc8 简要结论

- 固定评估 `20/20` 成功，平均速度从 `0.2191 m/s` 改善到更接近指令的 `0.2086 m/s`。
- rc8 单回合 cost 下降 `5.41%`，但单位距离 rc8 cost 仅降低 `0.65%`。
- 统一口径下的转子绝对能量降低 `0.27%`，10 关节绝对能量上升 `4.95%`，尚未显示出相对其他 cost mode 的绝对节能优势。
- 训练分布成功率为 `77%`，目前仅有单个 seed（随机种子），不足以对随机环境鲁棒性作最终排名。
