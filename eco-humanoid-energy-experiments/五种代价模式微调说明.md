# 五种代价模式微调说明

本实验从同一个原 ECO `model_3000.pt` 开始，对五种 cost mode（代价模式）分别微调 1000 iterations（迭代）。

## 固定参数

| 参数 | 值 |
|---|---|
| 来源 checkpoint（检查点） | `logs/exp/May27_16-06-41_Eco/model_3000.pt` |
| 来源 SHA-256 | `b8556ca4cdc6a166d2645ce34d19d283dcafb67c832dae883f14931bfb95e7db` |
| seed（随机种子） | `123` |
| num_envs（并行环境数） | `8192` |
| 速度 | `vx=0.1`、`vy=0` |
| terrain（地形） | `trimesh` |
| 微调迭代数 | `1000` |
| 训练采样 | 原 ECO 采样方式 |

## Warm-start（热启动）语义

`--warm_start` 会加载：

- actor（策略网络）；
- reward critic（奖励价值网络）；
- action noise standard deviation（动作噪声标准差）。

下列状态会统一重置：

- cost critic（代价价值网络）；
- policy optimizer（策略优化器）；
- cost optimizer（代价优化器）；
- Lagrange optimizer/multiplier（拉格朗日优化器/乘子）；
- iteration、计时与 rollout state（轨迹状态）。

因此微调从 iteration 0 重新计数，最终权重为 `model_1000.pt`。每个运行目录的 `warm_start_metadata.json` 和 checkpoint 内的 `initialization` 字段保存来源与重置信息。

`model_3000.pt` 文件内部保存的最后 iteration 索引为 `2999`（从 0 开始计数），与文件名代表完成 3000 次迭代一致。启动脚本会先校验来源文件的 SHA-256，不匹配时直接终止。

## 启动方法

每次启动一个 mode，第二个参数是物理 GPU 编号：

```bash
cd /home/xy.chen/tw/ECO-humanoid-remote/eco-humanoid-energy-experiments

nohup bash bruce_gym/scripts/run_vx010_finetune_from_eco.sh lja10 2 &
nohup bash bruce_gym/scripts/run_vx010_finetune_from_eco.sh ja8 3 &
nohup bash bruce_gym/scripts/run_vx010_finetune_from_eco.sh ra8 4 &
```

等第一批中对应 GPU 空闲后，再启动：

```bash
nohup bash bruce_gym/scripts/run_vx010_finetune_from_eco.sh jp8 2 &
nohup bash bruce_gym/scripts/run_vx010_finetune_from_eco.sh rp8 3 &
```

运行目录和终端日志均位于：

```text
logs/ECO-finetune-model3000/
```
